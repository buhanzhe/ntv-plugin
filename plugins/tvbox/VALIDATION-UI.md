# TVBox 布局与遥控器验证（2026-11-24）

沿用 TVBox v7 和 Release v1.0.5，未提高版本号。本次 TVBox JAR SHA-256：`58b978b04d6ff9476509199c0f40e20283dfb547075f7b5d51478f0f9117dc0a`。

界面按确认稿采用全幅内容背景、液态玻璃侧栏、横向推荐卡片、竖版海报墙和亮白焦点；搜索固定左上，无 TVBox 角标和电视直播导航。片名使用新宿主随附的 1999 版文鼎 PL 简报宋，时间、集数、按钮分别排版。完整验收表见 DESIGN.md。播放器与视频底色均为黑色；TextureView 使用单次、最长边 128 像素的取样模糊，无法取帧时使用渐变玻璃。Android 4.0–4.2 的圆角图片使用软件裁剪。

- 站点、歌曲、电影多线路选集、搜索和电影海报墙已截图检查，无空白内容区。
- 音乐封面 FIT_CENTER 且宽高一致；78 首条目完整，方向键从首项进入下一行。
