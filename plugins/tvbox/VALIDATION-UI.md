# TVBox 布局与遥控器验证（2026-11-24）

沿用 TVBox v7 和 Release v1.0.5，未提高版本号。本次 TVBox JAR SHA-256：`742d21e683d81e0c0f654bd7acdf3842d5a38b11a932b362a5bf20e4a6290577`。

界面改为深蓝渐变、半透明圆角侧栏、蓝色卡片与亮白焦点边框；移除左上角 TVBox 标识。站点、推荐、分类、搜索和配置使用同一套原生样式。背景渐变缓存，无实时模糊；Android 4.0–4.2 的圆角图片使用软件裁剪。播放器容器与宿主视频底色均为黑色。

音乐详情保留完整方形封面，宽屏左右分栏、窄屏上下排列。78 首多语言歌曲全部保留，长标题最多三列、两行显示，当前完整标题在列表上方显示；共同歌手前缀集中展示。电影短集名可用更多列。已修复加权布局重复测量导致方向键选中项回到首项的问题。

## Android 4.4.4 真机

Samsung SM-G3608 / ARM32，原签名 Bro 1.8.4（versionCode 12）：

- 站点、歌曲、电影多线路选集已截图检查，无空白内容区。
- 音乐封面 FIT_CENTER 且宽高一致；78 首条目完整，方向键从首项进入下一行。
- 普通点播、插件 DASH 均实际播放自有 90 秒 AVC/AAC 样本。
- 两条播放路径的右键单击均跳转约 5 秒；长按期间播放器保持原位置，松开后跳转到预览目标。
- 实际宿主 PlayerUi 另行验证左右各 5 秒、长按进度预览、重复事件去重、单次提交、取消/隐藏后不提交、反向按键与直播拒绝定位。

## 构建与回归

宿主 release 构建、AndroidTest Java 编译、最终 R8 宿主 ABI 检查通过。遥控器状态测试、现有定位回归和多站搜索回归通过。
