# TVBox v7 搜索与加载回归（2026-11-24）

设备：三星 SM-G3608 / Android 4.4.4（ARM32），MI 6 / Android 7.1.1（ARM32 进程）。宿主为原签名 Bro 1.8.4，TVBox v7；Python 沿用 v2 ARM32。

## 站点加载

本机可控 HTTP 样本给首页增加 700 ms、爬虫包下载增加 800 ms 延迟，用请求计数与耗时验证缓存。以下为一次设备回归的观测值，含约 120 ms 的等待轮询粒度，实际在线站点受接口耗时影响。

| 项目 | Android 4.4.4 | Android 7.1.1 |
| --- | --- | --- |
| 首次首页 → 同站重复进入 | 842 → 126 ms | 722 → 126 ms |
| 首次 JAR → 关闭再打开插件 | 1083 → 122 ms | 963 → 126 ms |

首页缓存最多 8 站、有效期 2 分钟，可手动刷新；爬虫包缓存按 SHA-256 校验，未固定 MD5 的地址 10 分钟刷新。单元回归覆盖过期、错误 MD5、损坏文件及系统时钟回拨。

## 多站搜索

两台设备均验证 CMS、ES module JS、Python requests 和 Java 爬虫同时参与搜索：快站先显示，慢站继续执行，一个 HTTP 503 不影响其他结果。相同 vod_id 的 JS/Python 结果分别进入各自详情；返回保留已有结果。停止后迟到响应不会进入页面，新关键词结果保持独立。后台 Java 搜索完成后，原来选中站点的本机播放代理仍可读取媒体。

4.4 并发 2 站，7.1 并发 3 站；总上限 60 秒，每站前 12 条、最多 160 条结果。Java 爬虫自建传输不一定支持宿主的网络取消机制，迟到结果仍会被丢弃。

## 易听王力宏

实源 MusicGuard 的内部 Music 没有实现 searchContent，并且延迟创建内部爬虫。补全初始化与站点公开搜索后，两台设备首次搜索“王力宏”均返回 82 条结果，包含《唯一》《爱错》《花田错》。重新选择站点后，《唯一》的详情仍指向原歌曲，没有进入默认推荐歌单。

Android 7.1 使用原爬虫播放器；4.4 原接口为空时使用该站公开网页播放器和原会话。两台均进入宿主实际播放，时长 262447 ms，观察到约 3 秒内进度递增超过 3 秒。搜索暖请求约 0.5～0.9 秒；首次会话初始化后的搜索约 1.2～1.8 秒。遇到站点验证页面会报错，不自动完成验证。

## 左侧频道点击

TVBox 浏览页和宿主点播期间，两台均注入真实左侧触摸，宿主频道面板保持关闭，歌曲继续播放。JAR 的 blockHostChannelClick 元数据由 Bro 1.8.4 读取；直接调用宿主入口也保持关闭。退出 TVBox 后，两台设备的宿主入口调用均恢复；4.4 的左侧触摸恢复已验证。7.1 当时的屏幕姿态下，退出后的测试点击没有展开面板，入口调用验证通过。返回键及插件内导航沿用原逻辑。
