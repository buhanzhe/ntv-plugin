# 影视与播放器界面验收

首页以用户确认的液态玻璃视觉稿为基准，使用真实站点元数据；不将视觉稿中的虚构影片写进产品。

| 页面 | 实现项目 |
| --- | --- |
| 首页 | 优先选择横向剧照，顶部控制在同一行；底部展示片名、简介及当前位置 / 总数。推荐每 6 秒轮播，左右键切换，点封面进入详情；「开始播放」或遥控器 OK 直接尝试首条线路，失败时右侧弹窗标明失败线路，焦点移到下一条 |
| 电影列表 | 全宽海报网格与顶部分类。列表末尾下键或上滑加载下一页；长按当前分类打开可用筛选，系统返回键回上一级 |
| 电影详情 | 宽屏左侧展示影片资料，右侧直接选线路和播放，窄屏上下排列。有效海报显示在简介旁；没有可用海报时，简介使用整列宽度。线路弹窗在当前页更新播放列表；文件保留容量、格式和长按查看完整文件名 |
| 音乐详情 | 不裁切方形专辑封面，资料与歌曲按屏宽分栏，长歌名两行、最多三列，当前完整标题；保留所有曲目和播放 ID |
| 搜索 | 顶部入口，多站/本站范围、输入框与九键遥控器键盘；连按切换字母、数字/空格/删除/清空，搜索结果使用海报卡片 |
| 站点/源地址 | 最多四列紧凑文字站点卡片，无重复默认图标；配置源只从 JAR 的 url 参数读取，无地址编辑/保存界面，也不读取旧保存地址。缺少参数时显示提示 |
| 播放器 | 黑色视频底色、底部浮动玻璃面板、系统字体片名、较小集名、实际分辨率、当前时间/加粗进度条/剩余时间、前后 5 秒、白色播放按钮、选集/音轨与字幕/倍速功能胶囊 |
| 页面按钮 | 按钮透出柔化后的背景，焦点半透明提亮并保留浅色文字。按钮/选集/焦点均按实际高度使用胶囊圆角；主次按钮内边距一致，标题栏与内容留出间隔 |
| 字体 | 首页片名使用系统粗体，固定两行高度；导航、片名和集数使用系统字体，时间使用系统等宽数字 |

站点没有影片 ID 的片单，主按钮转为搜索片名；分类来自实际配置。不虚构“继续观看”、历史进度、HDR、剧情或收藏状态。横幅封面无法取得时，可从同页已加载的真实推荐封面选择展示内容；全部封面均不可用时保留暗色底图。

玻璃控件在出现时对可用 TextureView 画面作最长边 192 像素的单帧取样与柔化；SurfaceView 等不可取帧路径使用透明渐变和轮廓。圆角与反光轮廓随尺寸缓存；加载期间保留播放按钮位置，避免出现空缺。不会持续逐帧截图，也不改变视频解码路径。

浏览页面将当前封面缩小至最长边 192 像素，Android 4.4 及更早版本使用 128 像素，在独立的单线程、有界队列上生成静态模糊图。分类页、搜索与详情保留柔化的环境背景，侧栏和胶囊从同一图层取样，使用连续的透光渐变、细边缘和轻反光。加载完成后检查封面代次，已离开的封面不会覆盖当前背景；退出时结束线程，不保存全屏截图或引入逐帧渲染。

玻璃仅参考 Tigris 的透色和柔和边缘，保留当前页面布局。取消两角贴图亮斑、金属渐变和不透明焦点底色；侧栏、按钮、站点和选集采用同一套背景取样与轻薄定向边缘。实现及参考链接见 [MATERIAL.md](MATERIAL.md)。旧 PNG、提示词存于 design/glass，不再打包。

浏览控件的玻璃采样、渐变与细边缘均使用抗锯齿圆角绘制；不通过 `clipPath` 对填充作硬裁切，避免旧版 Android 出现台阶轮廓，也不为每个按钮创建全尺寸中间位图。

图片使用有内存上限的 ARGB_8888 解码；缩略图可先显示，但不会阻止高清图继续加载。宽幅图片正常铺陈；竖版及过小海报保留右侧构图，以柔化背景承接，不将低清海报放大成全屏。海报圆角直接用 BitmapShader 抗锯齿绘制，不再依赖硬裁剪。移除片名的人工加粗，统一卡片间距、圆角和焦点描边；浏览页不叠加宿主的调试 URL。

截图和三张 image_gen 视觉素材保留在本地验收目录，演示素材不随插件发布。实测范围见 [VALIDATION-UI.md](VALIDATION-UI.md)。
