# 影视与播放器界面验收

首页以用户确认的液态玻璃视觉稿为基准，使用真实站点元数据；不将视觉稿中的虚构影片写进产品。

| 页面 | 实现项目 |
| --- | --- |
| 首页 | 全幅内容背景、左暗右亮遮罩、左上搜索、玻璃侧栏、推荐/分类标签与下划线、时钟、大号宋体片名、元数据、双按钮、每行最多四张横向卡片；片名覆盖在海报上 |
| 侧栏 | 搜索、影视、站点、分类、底部配置；当前封面的静态磨砂层、冷色透光和明暗边缘；圆头线条图标，影视使用胶片卷；无 TVBox 角标，无电视直播导航 |
| 电影列表 | 竖版海报墙、实际分类标题、当前分类下划线；仅在站点提供筛选时显示筛选入口 |
| 电影详情 | 横幅、宋体片名、真实简介、开始播放/搜索、选集数量、线路切换、圆角选集；焦点银白、深色文字 |
| 音乐详情 | 不裁切方形专辑封面，资料与歌曲按屏宽分栏，长歌名两行、最多三列，当前完整标题；保留所有曲目和播放 ID |
| 搜索 | 左上固定入口，多站/本站范围、输入框与遥控器键盘，搜索结果使用海报卡片 |
| 播放器 | 黑色视频底色、底部浮动玻璃面板、宋体片名、较小集名、实际分辨率、当前时间/加粗进度条/剩余时间、前后 5 秒、白色播放按钮、选集/音轨与字幕/倍速功能胶囊 |
| 页面按钮 | 返回使用钛灰玻璃胶囊和原生箭头；普通按钮透出柔化后的背景，遥控焦点变为银白底和深色文字；播放、搜索、刷新、筛选均用统一线条图标 |
| 字体 | 片名使用原版 1999 文鼎 PL 简报宋，不作人工加粗；优先使用宿主字体，缺少时在线校验下载并持久缓存，完成后自动更新标题；导航/集数用无衬线，时间用等宽数字，保留三种语言原始授权 |

站点没有影片 ID 的片单，主按钮转为搜索片名；分类来自实际配置。不虚构“继续观看”、历史进度、HDR、剧情或收藏状态。横幅封面无法取得时，可从同页已加载的真实推荐封面选择展示内容；全部封面均不可用时保留暗色底图。

玻璃控件在出现时对可用 TextureView 画面作最长边 192 像素的单帧取样与柔化；SurfaceView 等不可取帧路径使用透明渐变和轮廓。圆角与反光轮廓随尺寸缓存；加载期间保留播放按钮位置，避免出现空缺。不会持续逐帧截图，也不改变视频解码路径。

浏览页面将当前封面缩小至最长边 192 像素，在独立的单线程、有界队列上生成静态模糊图。分类页、搜索与详情保留柔化的环境背景，侧栏和胶囊从同一图层取样，使用连续的透光渐变、细边缘和轻反光。加载完成后检查封面代次，已离开的封面不会覆盖当前背景；退出时结束线程，不保存全屏截图或引入逐帧渲染。

PNG 材质仅作为低强度、径向渐隐的局部反光叠加在左上和右下，保留素材透明度；不把完整 PNG 铺成粗亮边框。底色覆盖降低，轮廓维持轻薄，反光在采样块内部边界前归零。侧栏、胶囊与播放器素材、提示词及接入说明见 `assets/glass/`。

图片使用有内存上限的 ARGB_8888 解码；缩略图可先显示，但不会阻止高清图继续加载。宽幅图片正常铺陈；竖版及过小海报保留右侧构图，以柔化背景承接，不将低清海报放大成全屏。海报圆角直接用 BitmapShader 抗锯齿绘制，不再依赖硬裁剪。移除片名的人工加粗，统一卡片间距、圆角和焦点描边；浏览页不叠加宿主的调试 URL。

截图和三张 image_gen 视觉素材保留在本地验收目录，演示素材不随插件发布。实测范围见 [VALIDATION-UI.md](VALIDATION-UI.md)。
