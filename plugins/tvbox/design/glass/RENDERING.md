# 液态玻璃 PNG 素材

本目录仅保留设计历史；当前界面已改为参考 Tigris 的轻量透色玻璃，不再加载或打包这些 PNG。当前实现见 ../../MATERIAL.md，以下说明描述旧方案。

素材由内置 image_gen 生成，保留原始 RGBA 与透明通道。完整提示词及胶囊透明度修订见 PROMPTS.json。

| 文件 | 用途 |
| --- | --- |
| liquid-sidebar-v1.png | 侧栏的局部曲面反光 |
| liquid-capsule-v1.png | 按钮、焦点胶囊的局部反光 |
| liquid-player-v1.png | 播放器面板的局部反光 |

实际界面以当前内容的柔化取样作为底层，并保留细描边。PNG 仅在左上、右下两个角以低强度叠加，经过径向遮罩渐隐；不将素材整张铺成明亮的完整边框。遮罩在采样块的内部边界之前归零，避免方形接缝。圆角和反光着色器按尺寸缓存。

侧栏及胶囊 PNG 中央的 alpha 为 0；播放器 PNG 中央保留少量半透明雾化信息。当前渲染仅使用边角反光，不把中央的浅色覆盖到视频或正文上。PNG 提供静态光学细节，背景柔化、文字、图标和交互由应用绘制。

使用原始透明 PNG，不要铺成不透明底图、烘焙黑底或将整个描边设置为高亮。Android 4.4 已检查透明度、标题可读性、普通态、焦点态及播放器显示；未更改应用版本号或 versionCode。
