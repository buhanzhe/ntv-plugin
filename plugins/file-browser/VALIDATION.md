# v2 玻璃界面与 Android 4.0.4 验证

日期：2026-11-23。设备：三星 GT-N7005，Android 4.0.4 / API 15。
独立测试 APK 通过 DexClassLoader 加载发布 JAR，未覆盖安装正式 nTv 或清除其数据。

最终 JAR SHA-256：`1a45fa94d7b4372ba9f2af888ae470fd9ed520398ac2e6586ff163fc42be2ed4`。

## 功能与界面

- 深蓝静态玻璃背景、左侧位置导航、蓝色立体图标及焦点描边。
- 标题图标与“文件”间隔 9dp；卡片图标保持宽高比，与标题左对齐，图标下方留出空隙，标题/说明基线统一。
- 本机文件夹与视频过滤、遥控器选择/返回；本机与免密 SMB2 的实际 640×360 H.264/AAC 解码。
- 播放复用网页电视 VideoControlsOverlay 同源控制层；暂停继续、向前跳转 10 秒、前后台恢复、返回释放播放器和代理端口。
- 局域网自动扫描、选择设备后自动尝试空账号密码；独立免密测试共享的中文/空格文件名及随机读取。
- 11,803,893 字节视频在传输 2,424,832 字节时已出现画面，无需完整下载。
- 修复 4.0.4 缺少 Cp850 的初始化问题；SMB1 禁用，SMB2 路径使用 Unicode。

## 性能观测

- 背景 256×144，四类图标各 224×196；RGBA 像素缓存总计 849,920 字节（约 0.81 MiB），按需生成并跨卡片复用。
- 目录中 600 个扩展名为 .mp4 的测试文件，仅实例化 6 张可见卡片；不扫描整个目录生成视频封面。
- 20 次跨位置浏览时，16ms 主线程心跳的间隔 P95 为 55ms（58 个样本）。
- 原尺寸离屏软件绘制 24 次（预热 4 次后），耗时 P95 为 42.79ms。
- 探针进程 PSS 为 13,188 KiB；当次 Java 堆已用约 17,683 KiB。PSS 与堆统计口径不同，不应相加。
- 目录页没有动画、实时模糊或持续刷新；绘制复用材质、位图与裁切好的文字。旧系统 SMB 扫描使用 8 个工作线程。
- 加载转圈只在可见时运行，API 15 使用约 32ms 间隔；控制层隐藏/后台时停止时钟刷新。

这些数值是该设备当次负载下的队列响应与离屏软件绘制观测，并非显示帧率、硬件渲染时间或无卡顿承诺，未用未经控制的两次测试宣称加速百分比。
